# Miras Studio

Yaratıcı ajans web sitesi demosu (statik HTML/CSS/JS, GitHub Pages ile yayınlanır).

- Tüm görseller kod ile çizilir (SVG/CSS); harici görsel veya video dosyası gerekmez.
- Demo markalar (Rota Turizm, Burger Atölyesi vb.) kurgusaldır. Gerçek müşteri işleri `main.js` içindeki `B`, `FILMS` ve `WORKS` listelerinden değiştirilir.
- İletişim formu demo modundadır; gerçek talep almak için Formspree gibi bir form servisine bağlanmalıdır.
